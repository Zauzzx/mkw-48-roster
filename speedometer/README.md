# Speedometer digits

Put the speedometer's 13 textures here (they are not in the repository):

    som_d_number_3d_00.tpl ... som_d_number_3d_09.tpl
    som_d_number_3d_coron.tpl   the dot
    som_d_none.tpl              an empty digit
    speed.tpl                   the KM/H label

Any colour of the [Speedometer Recolor Pack](https://mkwiiki.org/wiki/Speedometer_Recolor_Pack)
works: copy the files of the colour you want into this folder. Then run
`tools/pack_assets.py` again.
